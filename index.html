DPC Tujuan

Pengaturan Sinkronisasi Dual-Sync SIDAK

Konfigurasi terpisah untuk Supabase SIDAK, Backup JSON GitHub, dan Sumber Master Kader.

Skema SQL Tabel Supabase ("sidak_data_utama")

Jalankan pada SQL Editor proyek Supabase baru Anda untuk menyiapkan tabel SIDAK.

CREATE TABLE IF NOT EXISTS public.sidak_data_utama (
  id TEXT PRIMARY KEY,
  tipe_data TEXT NOT NULL CHECK (
    tipe_data IN ('gsd_sahabat', 'gsd_mitra', 'masjid_binaan', 'dpc', 'kader_master')
  ),
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.sidak_data_utama ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Akses Publik SIDAK" ON public.sidak_data_utama
  FOR ALL USING (true) WITH CHECK (true);
Endpoint GitHub REST API (Terpisah dari SIKAD) https://api.github.com/repos/[USERNAME]/[REPO]/contents/sidak_backup.json
